# E-Commerce Performance Analysis

### Project Overview
This data analysis project aims to provide vital insights into some key performances of an e-commerce department store called Olist in Brazil over the past year. By poring over and analyzing various aspects of the orders/ sales data, we seek to identify crucial business insights, make data-driven actionable recommendations to streamline certain processes and logistics, and finally gain a deeper understanding of the store's performance.

### Data Sources
Orders Data: The dataset used for this analysis is the Olist's 'olist_order_dataset.csv' file, containing information about each sale made by the store.

### Tools
- pandas for Exploratory Data Analysis (EDA)
- matplotlib for visualization
- seaborn for visualization

### Data Cleaning/ Preparation
In the initial data preparation phase, we performed the following tasks:
1. Data loading and inspection
2. Checking and handling null/ missing values
3. Data cleaning and formatting

### Exploratory Data Analysis (EDA)
EDA involved exploring the orders data to answer several key questions such as:
1. What does the order status distribution look like?
2. What is the average delivery time?
3. What is the quantiles of delivery times?
4. The monthly order volume trend
5. What is the percentage of orders delivered early, on-time, or late?
6. What is the cancellation rate?
7. What is the repeat purchase rate?
